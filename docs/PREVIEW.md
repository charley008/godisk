# goDisk 0.3.4 测试版

goDisk — Disk Health & Performance Monitor
Windows 11 x64 磁盘健康检测与性能测试工具

测速引擎为 Microsoft DiskSpd 2.3 x64。可用标签栏右侧的「深色主题」开关或「查看」菜单切换。首次启动跟随 Windows 外观，手动切换后记住选择。

新引擎的高队列 I/O 实现与 2.0.21a 有差异。同一块磁盘在不同引擎版本下的成绩可能变化，历史结果仍显示原始数值和引擎版本。

## 开始测试

健康页启动时读取设备，随后每 30 秒自动更新。测速期间暂停，结束后恢复。磁盘较多时可沿顶部的横向滚动条查看更多设备。

1. 解压整个 ZIP，双击 `goDisk.exe`。通过顶部磁盘条切换设备。窗口标题显示磁盘型号与采集时间，正文显示设备摘要与 SMART 表格。点击序列号可查看完整值。传输模式依次显示当前链路和设备报告的最大链路，依赖驱动支持。NVMe 预计剩余寿命按 `100 − Percentage Used` 计算，下限为 0。磁盘容量采用十进制 GB，累计读写采用整数 GiB；悬停在 SMART 累计读写的读数上可查看精确字节数。
2. 在「文件」菜单打开或导出 NVMe 健康快照。导出文件包含 512 字节标准健康日志、采集时间及 SHA-256，请用新文件名保存。
3. 打开「性能测试」，选择目标卷与测试文件大小，默认 1 GiB。点击「开始测试」直接运行。四个默认测试项目分为顺序 1 MiB（Q8T1、Q1T1）和随机 4 KiB（Q32T1、Q1T1）。每个项目预热 5 秒，默认测量 5 秒，项目之间间隔 5 秒。写入项目默认关闭。读项目也会先在目标卷填充指定大小的临时文件。
4. 可切换 MB/s、MiB/s、IOPS、平均和 P99 延迟。测试期间可取消；加长测量时间、调整项目、次数及自定义线程和队列请使用「测试 → 高级设置」。
5. 「历史记录」只列出测速，每条显示第一项顺序读取速度，默认项目为 1 MiB Q8T1。点击记录可看完整结果。数据库位于 `%APPDATA%\goDisk\history.sqlite`。

## 当前边界

- 已在 Windows 11 x64 普通权限下验证三块直连 NVMe、顺序和 4 KiB 随机读、测速取消与正常清理。界面中的测量进度由计时估算，结果取实际 XML；吞吐量和 IOPS 取最高已完成轮次。CrystalDiskMark 8.0.6 使用独立进程预热，goDisk 在首轮进程内预热。对照时使用同一卷、相同项目、文件大小和测量时间。
- SATA/ATA SMART 通路为实验性，本机缺少直连 SATA 设备，尚未实测。USB 桥接、VMD/RST 和 RAID 的私有 SMART 通路留待后续验证。
- 健康摘要的转速来自 ATA IDENTIFY DEVICE 字 217，有效数值显示为 RPM，非旋转介质显示为 SSD。控制器未提供可识别的转速时显示未知。
- 已在 E: 上使用 DiskSpd 2.3 验证随机 4 KiB Q32T1 写入。本版仅接受有盘符、归属单块物理磁盘的本地固定卷用于测速，目标卷需给当前用户创建临时目录的权限。
- 测速正常完成或在应用内取消时会清理临时文件。如果整机或应用异常停止，磁盘根目录可能遗留 `goDisk-test-*` 目录。确认无测速进程在使用后，可手动检查其中的 `goDisk-test.dat`。本版无自动恢复清理界面。
- Windows x64 便携包由 GitHub Actions 构建，包含从微软 MIT 源码编译的 DiskSpd 2.3。goDisk 在启动测速前会核对包内 `diskspd\diskspd.exe` 的 SHA-256。保留解压目录的文件布局即可直接运行。 [第三方许可](THIRD_PARTY_NOTICES.txt)
